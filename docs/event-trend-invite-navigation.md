# 活动、体重图与邀请入口

活动广场全国/地区一行始终存在，位置不受“我的”影响；“我的”在主标签下增加参与记录/领奖记录。个人记录也遵循当前范围，全国保留原全范围浏览逻辑，地区保留本地及全国活动逻辑。个人列表仍仅包含本人报名/领奖。

体重图7天固定今日前后各3天，5周为本周前后各2个自然周（周一至周日），3个月为本月前后各1个自然月。日取最后一次有效记录；周/月按每日最后一次记录计算中位数。没记录的桶留空且不跨缺失桶连实线，不生成未来真实记录。实际为蓝色实线和蓝点，预估为橙色虚线，图例一致。预估来自已有当前体重/目标/目标周期，当前桶从今日体重起算，未来周/月代表点为该桶中间日期。

邀请首页移除活动档位和两类记录长列表。我的邀请、邀请活动、奖励记录分别打开 invite-data?mode=records|activities|rewards 独立页面。当前活动含进行中及尚可领奖的活动，不展示未开始或过期档位。历史个人奖励不受当前活动过滤影响，不跳转管理员账本。共享 loadInviteDashboard 获取本人记录；邀请活动强制使用账号地区，首页浏览其他地区不会影响个人领取资格。通用奖励页原浏览地区逻辑不变。

三项入口仍使用当前本地模拟服务，原生页面已注册到主题与路由；需手机端继续确认实际触控及微信表现。
