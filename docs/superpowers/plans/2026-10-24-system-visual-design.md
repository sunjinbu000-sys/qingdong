# 全系统视觉梳理

按用户给出的首页参考，在既有功能与布局上统一视觉层级。五个底部导航分别使用柔紫、薄荷绿、青碧、暖金、丁香色；小队沿用青绿，活动杏桃，体重雾蓝，计划草绿，权益暖金，管理灰蓝。

1. 建立所有已注册路由的明确主题映射，覆盖页面背景、导航栏、公共控件。启动广告保留媒体全屏，帖子详情保留白色阅读面。
2. 统一卡片圆角、边框、阴影、正文与次要文字对比度；按语义区分主要操作、次要操作、危险操作和禁用状态。保留既有数据图表、表单、固定操作栏和点击事件。
3. 首页与健康日记入口用目标模块色，进入后的页面延续该色。重绘底部导航轻量线条图标，统一业务 SVG 图标颜色与尺寸；真实食物照片和现有插画保留。
4. 逐一处理首页、日记、论坛、挑战、我的，以及小队、活动、体重、计划、食谱、邀请等主要页面的遗留硬编码配色。
5. 回归检查所有路由主题覆盖、颜色可读性、入口映射、原有业务测试和微信编译；用真实编译 WXML 预览五个主导航和主要详情的320/390宽度。

实现采用共享 WXSS 视觉规则与静态路由主题，避免新增运行时样式依赖或大图资源。页面功能与数据协议保持原有行为。
