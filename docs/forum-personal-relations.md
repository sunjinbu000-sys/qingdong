# 论坛个人互动列表

个人区的关注、粉丝、获赞计数均可点击，分别进入 `forum-relations?type=following|followers|likes`。

- 关注：列出自己实际关注的轻友，可查看公开资料、取消关注。
- 粉丝：列出实际关注自己的轻友，支持回关和互相关注状态；对方没有公开笔记时也可回关。
- 获赞：按点赞者聚合自己已审核公开笔记的实际点赞记录，采用圆形爱心、提示标题、真实昵称和“去回赞Ta”通知卡。同一人点赞多篇笔记显示实际累计次数，点击次数展开对应笔记；总获赞数仍为点赞次数。“去回赞Ta”打开对方公开主页，由用户自行查看、点赞。自己点赞别人的笔记不计入获赞，不补造年龄或时间。
- 搜索按昵称匹配，获赞额外支持笔记标题；清空恢复完整列表。计数不受搜索筛选影响。
- 页面采用白色列表、顶部搜索、圆形默认头像、昵称、右侧关注操作和细分隔线，延续青碧论坛主题。不提供资深/全部筛选，不显示天数、发帖量或虚构在线状态。

新接口 `getForumRelations(type)` 只查询当前登录用户，无目标用户参数。投影不返回健康数据、匿名帖身份、审核日志或举报信息；拉黑关系从计数与列表同时过滤。返回论坛时通过现有页面刷新更新计数。

页面空数据展示实际空状态，不补造人物或互动。数据来源仍为现有本地模拟服务。
