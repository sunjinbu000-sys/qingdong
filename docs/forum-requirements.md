# 轻友论坛页面（2026-10-22）

按本次用户需求替换原有论坛筛选栏，保留既有详情、图文编辑、人工审核、点赞、评论与收藏服务。

- 顶部固定顺序：推荐 / 本地 / 全国 / 最新 / 我的。
- 推荐展示人工设置推荐且已通过审核的文章；全国展示全部公开文章并按互动热度排序；最新按创建时间排序。
- 我的分为“我的文章 / 我点赞的 / 我评论过的”。我的文章包含本人草稿、待审核、已通过、被拒及撤回状态；点赞与评论列表只显示仍公开的文章。
- 底部居中固定发布按钮位于列表及状态分支之外，切换 Tab、加载、空列表及滚动均保留。页面底部留出按钮和安全区空间。
- 发布支持文字及最多三张图片，复用拍照/相册和本机图片持久化。发布前必须主动选择分类；草稿可暂不选择。文章及图片提交人工审核，通过前不向公众展示；编辑后重新审核。
- 本地范围按用户确认的“同一城市”实现。点击定位本地打开微信地图，由用户确认当前位置；从地图地址提取城市，筛选该城市公开文章。只存储城市名称，不保存经纬度或详细地址，不修改个人资料中的城市。
- 未定位时显示定位入口，不回退为账号城市；取消保持原状态，拒绝授权或无法识别城市时显示提示。

## 接口

`listForumPosts({feed, mode, sort})`：feed 为 recommended/local/national/latest，mode 为 public/mine/liked/commented/draft，兼容既有调用。

`getForumRegion()` / `saveForumRegion({city, source:'map'})`：独立的论坛城市选择。新文章优先归属已确认的地图城市，否则沿用作者档案城市；旧文章编辑保留原城市。

## 验证与接入

自动测试覆盖各列表资格、未审核内容隔离、个人互动、分类必选、城市独立于档案及地图城市提取/取消/拒绝授权。真实开发者工具模拟器验证五个 Tab、固定发布按钮滚动前后坐标不变；截图见 previews/native-forum.png。

app.json 已声明 chooseLocation 及用途。真实微信地图能力仍需小程序后台相应接口权限和隐私声明，并在真机验证授权与当前位置。当前城市解析测试使用模拟地址，未冒充真实 GPS 测试；接口声明参照[微信官方小程序示例配置](https://github.com/wechat-miniprogram/miniprogram-demo/blob/master/miniprogram/app.json)。后端未接入，文章与审核数据仍在本机模拟。
