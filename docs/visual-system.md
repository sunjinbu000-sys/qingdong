# 轻动全系统视觉规则

同一功能的入口、页面底色、筛选、主按钮、详情及原生导航延续同一配色。五个底部导航使用同一套72px线条图标，选中状态显示对应模块色与淡色底。原有首页3D插画与真实食物照片保留。

| 导航或模块 | 色彩 | 页面识别 |
| --- | --- | --- |
| 首页、拍餐识别 | 柔紫 | 拍照营养主视觉与轻量入口 |
| 健康日记、食物库、营养日历、饮食与运动记录 | 薄荷绿 | 日期、当天概览与记录操作 |
| 轻友论坛、个人笔记、帖子详情、评论 | 青碧 | 关注、话题、评论、发布与阅读 |
| 挑战、榜单 | 暖金 | 奖励、坚持进度与排名；保留挑战卡的绿/杏/蓝层级 |
| 我的、健康档案、隐私与设置 | 浅丁香 | 个人资料与功能分组，入口图标使用目标功能的颜色 |
| 我的小队、邀请入队、队伍详情与说明 | 青绿 | 同行、打卡、成员与小队状态 |
| 活动广场、详情、报名、邀请好友 | 杏桃 | 线下活动与邀请入口 |
| 体重趋势、体重记录 | 雾蓝 | 实际曲线用蓝，预估曲线保留绿色虚线 |
| 轻动计划 | 草绿与奶油 | 档案、风格、运动偏好、目标与报告 |
| 会员、勋章、奖励和订单 | 米金 | 权益与成长 |
| 管理与配置 | 灰蓝 | 表单、审核和运营工具 |

## 共同样式

- 页面使用很浅的模块色到白色渐变；主要内容采用白色卡片、30rpx圆角、细边框和低强度阴影。
- 标题采用深色，次要说明加深以保持可读；主按钮白字配模块深色，次按钮采用淡底，删除等危险动作保留红色语义。
- 首页保持用户确认的八宫格顺序与紫色营养插画、杏桃俱乐部横幅。日记和个人页入口依据目标功能配色，不按列表顺序轮流换色。
- 日记的日期与选中状态、小队说明弹窗、论坛个人区与评论、活动报名操作、体重筛选和食物列表都沿用所属模块。
- 启动广告保持全屏媒体；帖子详情保持白色阅读面；真实图表、任务状态及预估曲线保持各自语义。

## 实现与检查

`utils/theme.js` 为路由与原生导航的主题来源，`styles/themes.wxss` 定义共享样式。页面JSON提供静态导航颜色，公共页面生命周期同步底部导航选中色。无主题API的测试或旧客户端会跳过调用。

验证覆盖64个注册路由、动态入口及图标资源；主题主按钮白字对比度至少4.5，标题对比度至少7。十个底部导航PNG合计约21KB，主包源文件合计约1.96MB。未增加大图依赖。

通过微信 WXML/WXSS 编译和现有业务测试；使用实际编译模板检查五个主导航及16个主要业务页，在320/390宽度检查溢出和图片加载，并另检查论坛个人区和小队说明弹窗。此预览不代替手机端最终视觉验收。
