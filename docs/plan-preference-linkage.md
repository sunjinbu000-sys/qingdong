# 轻动计划生成联动检查

页面：`pages/ai-plan`。调用：`services/index.generateAIPlan` → `growth-full.generateAIPlan`。

| 输入 | 保存或生成结果 |
| --- | --- |
| 最新个人档案、当前体重 | `profileBasis` 固定生成时快照；已设置且符合现有规则的热量预算影响食材份量与示例餐单总热量 |
| 周期、目标斤数 | 周期日期与天数；目标范围校验；需要确认时进入原有记录模式 |
| 餐食风格 | 家庭日常、减脂餐或交替搭配，改变实际食材池、做法与餐次标签 |
| 减重风格 | 温和慢减默认15分钟、高效速减默认30分钟、塑形维稳默认20分钟；改变搭配轮换起点；不提高减重速度上限或降低餐单下限 |
| 运动选择或自填 | 目录项目采用标准名称；自填保留用户名称；逐日保存到运动安排 |
| 每日分钟数、活动时段 | 自填分钟数优先保留；不得超过所选时段（支持跨午夜）；超出时提示调整，不静默截短 |
| 忌口 | 合并档案忌口与当前计划临时限制，支持顿号、逗号、分号、空格；不把临时限制写回档案 |
| 身体补充 | 保留到报告和导出；需要确认时保留运动偏好与期望分钟数，不自动安排执行量 |

重复生成会改变餐单轮换起点。换一餐采用该计划保存的风格、预算、忌口和轮换起点；历史计划不会随当前表单修改。重新打开页面恢复最新保存的偏好，返回页面不会覆盖正在编辑的表单。

文本及 Excel 包含每日运动、分钟数、活动时段与风格；计划安排不会冒充实际已完成记录，自填运动不推算热量。生成失败不扣额度、不替换原报告，并在生成按钮附近显示原因。

验证包含服务与页面联动回归、全量测试、微信 WXML/WXSS 编译及320/390宽度的编译页面预览。当前配置为 `mode: mock`、`baseUrl: ""`，没有远程生成接口；本次不代表真实 AI、远程后台或手机运行验证。
