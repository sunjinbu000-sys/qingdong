# 小程序开屏展示

配置位置：运营工作台 → 设置 → 广告赠次与广告位 → 小程序全屏开屏展示。总部/管理员可维护，默认关闭。

支持图片 HTTPS 链接、视频 HTTPS 链接、微信流量主插屏广告位 ID（adunit-…）三种来源；视频静音自动播放。自有素材可设 3—60 秒展示时长、0—展示时长秒的跳过等待，每用户每天 0—100 次（0 表示不展示）。图片按铺满展示，视频铺满播放。

从外部进入或回到小程序时触发一次检查，内部页面切换不触发；使用 navigateTo 展示独立开屏页，关闭后 navigateBack 保留原入口、查询参数及邀请流程。自有素材播放完成、超时、可跳过或加载错误后放行；腾讯原生广告的样式及关闭由微信控制，不能将普通广告联盟网页链接直接当作广告位。开屏广告不发放激励视频奖励。

频次使用北京时间业务日期，已登录按用户、游客按本机存储隔离；先预约再确认实际图片加载/视频播放/原生广告 show 成功，失败不计次，预约 90 秒后释放，重复确认幂等。带 adFree 权益的有效会员不展示。

当前工程服务模式是 mock，管理配置与计次仅在本机持久化，并非已上线的集中后台。正式上线需把 get/saveStartupConfig、begin/finishStartupDisplay 替换为服务端接口，以真实用户身份原子限次。游客跨设备无法统一识别。素材需可访问的 HTTPS 地址及微信公众平台域名配置；腾讯广告需开通微信流量主、有效广告位，并进行微信真机验证。原生 SDK 可能无填充或因平台规则拒绝展示，失败直接返回。

测试：tests/startup-display.test.cjs 覆盖权限与配置验证、每日限次、跨日、失败释放、预约过期、用户/游客隔离、重复回调、启动路由保留、媒体跳过与原生广告回调。原生 WXML/WXSS 编译检查另运行。
