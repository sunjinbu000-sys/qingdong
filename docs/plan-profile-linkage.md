# 轻动计划与个人健康档案联动

- 页面每次进入时读取与生成服务相同的档案来源：年龄、性别、身高、本人最新有效体重、目标体重、方向、健康状态、自设热量、周期与忌口。
- 计划周期和减重目标由档案预填，用户可调整本次周期、目标与活动时段；档案的忌口和本次补充限制取并集，无法通过清空本次输入绕过过敏限制。
- 生成服务重新读取档案，不信任客户端传入的旧个人资料。最新有效体重优先于起始体重。
- 用户自行设置的热量目标仅在既有规则允许的普通模式下应用；记录/需要专业确认模式不套用该热量目标，也不执行量化减重活动。餐食、营养及份量仍是本地模拟估算，并非真实 AI 或医疗方案。
- 每份新计划保存生成时的 profileBasis。历史计划保留当时资料与限制，查看历史不会覆盖当前档案输入；修改档案后需重新生成才影响新计划。
- 页面明确显示同步档案、生成依据与当前模拟状态。后端真实 AI 接入前不宣称已完成真实模型推理。

验证：98 项测试通过；新增覆盖最新档案和体重读取、过敏限制不能清空、热量目标同步、历史快照保留以及记录模式约束。原生编译和 320/390 宽度显示检查通过。
