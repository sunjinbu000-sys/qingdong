# 建议餐风格与食材轮换

- 下拉选项：减脂餐（默认）、家庭日常、混合搭配。
- 风格存入计划 request.mealStyle。每餐保存实际风格标签；混合模式交替使用家常和减脂搭配。
- 早餐使用独立的主食、蛋白质和蔬果候选；午晚餐轮换普通谷薯、肉蛋豆和时蔬。家常搭配与减脂搭配使用不同主食、蔬菜候选与做法提示。
- 优先普通鸡肉、鸡蛋、豆腐、普通鱼、米面谷薯和时蔬，不把进口食材、补剂或昂贵食材作为必要条件。价格不作固定承诺，按地区和季节选购。
- 生成与换餐都过滤档案和本次输入的忌口并集；小麦限制同时识别面条、面包和馒头。实际商品仍需核对标签和交叉接触风险。
- 换一餐沿用该计划保存的风格与热量设置；旧计划无风格字段时按减脂餐兼容。
- 营养与份量仍为本地模板模拟估算，不能宣称保证个体营养充分或医疗效果；风格切换不放宽计划目标保护规则。

食物多样与合理搭配参考：[国家卫生健康委关于《中国居民膳食指南（2022）》的说明](https://www.nhc.gov.cn/wjw/jiany/202301/bd6c614391274ebd955fc9018f2032a2.shtml)。不采用单一食物或不吃主食的极端默认方案。

验证：104 项测试通过，包括默认选择、三种风格、7 天 21 餐中至少15种组合、档案忌口、麦类过滤、换餐保持风格、无效风格不扣次及三年计划存储体积回归。编译与320/390宽度显示检查通过。
