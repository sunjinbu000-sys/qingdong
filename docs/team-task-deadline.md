# 小队三项任务与早起截止时间

- 新小队自动启用每日签到、早起打卡、体重记录三项任务；创建页直接呈现，不能取消其中一项。
- 队长必须主动选择早起截止时间，创建页不预填。未选时不创建小队、不进入确认，提示并滚动到 `#team-early-time`。设置入口在主表单中，不隐藏在高级设置内。
- 时间采用北京时间，支持00:01至23:59；00:00没有当天可完成的时间窗口，禁止保存。
- 队长与队员执行同一规则：当前时间严格早于截止时间才接受早起打卡，到点及以后拒绝。不提供补早起操作。
- 每日签到从当天00:00至次日00:00前均可完成；每日去重，跨北京时间零点重新计算当天。
- 体重任务仍须先保存当天体重，再完成任务。新队完成率分母同步按三项任务统计。
- 确认弹窗、小队详情任务提示、邀请预览和玩法说明均显示对应规则与截止时间。
- 已有小队保留任务配置；没有保存截止时间的旧队沿用此前08:00规则。
- 创建页直接展示加入方式选择器、自定义人数及开始/结束日期，不再折叠在“更多组队设置”中，也不重复展示加入方式。
- 小队详情标题为“今日任务”。每个任务各自展示当日已打卡与未完成伙伴、人数、分享小队提醒及查看未完成成员入口；未开赛或已结束时不将成员误标为今日未完成。
- 任务成员页延续论坛搜索列表，支持按昵称搜索。仅本小队成员可查看，按所选任务及当日资格过滤，不返回体重值或原始健康记录。提醒使用微信原生分享，由用户选择好友或群，链接保留所选任务。

验证覆盖空值/无效时间阻止创建、页面自动滚动、三项任务、防重复确认、队长和成员截止前/到点/截止后、全天签到及跨日、旧队兼容、三项任务分母、邀请及窄屏显示。当前仍使用项目现有本地模拟数据服务。
